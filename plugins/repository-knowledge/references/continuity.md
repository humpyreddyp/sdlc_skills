# Investigation continuity

Published knowledge holds resolved understanding. One Markdown record per connected investigation holds only necessary unfinished context. Keep it in the investigated repository, following conventions or `docs/work/investigation/<question>.md`.

Save question and scope, relevant progress with links to published conclusions, open decisions and dependencies, next actions, and source context sufficient to recheck findings. Include relevant paths, revision information, and uncommitted changes; a commit ID alone cannot describe a dirty working tree. Link the original delivery request and other records needed to continue.

Update when an unresolved question or next action changes or the session is about to pause. Do not log every search/message, duplicate published explanations, create separate JSON/YAML saved state, or preserve human answers/transcripts by default. Temporary evidence maps and publication plans can stay in working context.

On resumption, read the record and relevant published pages, inspect current source changes, and recheck affected findings. Continue the next unresolved action without a routine recap or unrelated reinvestigation. Records must work in fresh Codex and Claude Code sessions without prior chat history or host-specific session IDs.

Remove a completed record only when useful conclusions are published, remaining implementation work is recorded or linked elsewhere, no unfinished task depends on information unique to the record, and incoming links have been updated. No separate archive is required by default. Preserve remaining questions in the connected record or an appropriate remaining record before removing the completed part.

Pending implementation alone is not an unfinished investigation. Once the requested evidence or intent question is resolved, put remaining application work in its existing delivery home, or create a minimal delivery note if none exists; then remove the completed investigation record. Do not keep resolved understanding in a work record or expand the investigation with questions unnecessary to the original request.
