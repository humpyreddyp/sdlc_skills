# Knowledge

A local task list lets one person add, list, and complete tasks by numeric ID, with the CLI storing tasks in a local JSON file. The typical journey is to add a task, list tasks to find its ID, then complete it. See the [README](../README.md) for runnable examples and product scope.

- [Task completion](completion.md): current rules, CLI persistence and errors, and the relevant implementation and tests.
- [Setup, checks, and readiness](../README.md#verification-and-readiness): prerequisites, verification commands, actual check results, and coverage limits for further work.
- [Future export work](export-notes.md): an existing proposal; CSV export is not implemented.
